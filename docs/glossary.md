# Глоссарий

| Термин | Определение |
|---|---|
| Рекламная нагрузка | Среднее количество рекламных показов на одного пользователя в день. |
| CPM | Cost Per Mille — стоимость 1 000 рекламных показов. |
| ARPU | Average Revenue Per User — средний доход от одного пользователя за месяц. |
| Churn | Доля пользователей, прекративших пользоваться сервисом. |
| CAC | Customer Acquisition Cost — стоимость привлечения одного пользователя. |
| Отток | Количество пользователей, ушедших из сервиса из-за рекламной нагрузки. |
| Чувствительность | Анализ изменения результата при изменении одного или нескольких параметров. |
