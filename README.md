# Задача 4. Оптимизация рекламной нагрузки для платформы видеоконтента

Проект содержит воспроизводимое решение экзаменационной задачи по курсу «Экономика информатизации».

## Структура

- `data/task_04_ad_load_config.json` — исходные параметры задачи;
- `notebooks/task_04_ad_load.ipynb` — Notebook с расчётами, таблицами, графиками и выводами;
- `utils/calculations.py` — переиспользуемые функции расчёта;
- `reports/` — автоматически формируемые изображения и HTML-отчёт;
- `docs/` — методика, глоссарий и памятка для защиты.

## Запуск

Из корневой папки проекта:

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

Открыть `notebooks/task_04_ad_load.ipynb` и выполнить все ячейки сверху вниз.

Notebook использует данные из JSON, поэтому при изменении исходных параметров таблицы, графики и итоговые выводы пересчитываются автоматически.

## Методологическая оговорка

В условии потери оттока заданы формулой `Отток × CAC + Отток × ARPU × 24`. Она приводит к большим потерям, чем таблица из решения для преподавателя. Поэтому Notebook показывает основной расчёт строго по формулам условия; все таблицы и выводы формируются из JSON.
